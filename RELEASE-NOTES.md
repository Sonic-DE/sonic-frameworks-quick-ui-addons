# Sonic Frameworks Quick UI Addons Release Notes

Sonic Frameworks Quick UI Addons adds extra ready-made building blocks, such as settings pages, date pickers and about pages, to modern SonicDE apps.

## 1.13.1 (2026-08-04)

- Apps built on these components now fall back to SonicDE's Silver style and Silver icons instead of Breeze, so nothing looks out of place.
- Behind the scenes: better support for code editors and restored the project's code formatting rules.
